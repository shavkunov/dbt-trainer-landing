# Опора — лендинг

Статический лендинг DBT-тренажёра (продукт: [`dbt_trainer`](../dbt_trainer)). Один HTML, один CSS,
самохостинг шрифтов, без сборки и без внешних запросов. Отдельный репозиторий от продукта —
обоснование в `dbt_trainer/planning/LANDING_PLAN.md`.

Рабочее название — **Опора**. DBT упоминается как методология, а не как услуга.

## Арт-дирекция

**Палитра и настроение — вариант A («дыхание»):** тёплый песок, шалфей, глина. Светло и спокойно.
Тёмная версия была отвергнута: читалась как надгробие, что для этой тематики недопустимо.

**Форма — идея варианта E («просвет»),** но не его исполнение. Одна скошенная щель проведена через
логотип, скосы кнопок, маркеры лейблов, левый край карточек и футер.

Главный аттракцион — **«три попытки»**. Это и есть продукт: одна и та же реплика переписывается
на глазах, с каждой попыткой формулировка точнее, критериев навыка закрывается больше
(3 → 5 → 6 из 7), оценка растёт (6 → 10 → 12 из 14), свет позади карточки разгорается.
Цикл 15.3 секунды, по 5.1 на попытку. Вокруг — кольцо в ритме дыхания 11 секунд.

Почему так, а не абстрактная фигура: аттракцион обязан быть про продукт. Заголовок обещает
«отрепетируйте» — анимация буквально показывает репетицию и то, что получается лучше.
Это позитивно и проверяемо, в отличие от декоративного объекта.

Реализация — только CSS: три варианта текста лежат в одной ячейке грида и сменяются по
`animation-delay`, высота зарезервирована под самый длинный, короткие центрируются, чтобы карточка
не прыгала. При `prefers-reduced-motion` показывается сразу третья попытка — лучший вариант ответа.

**Четыре шага — pinned-сцена** по механике `proto/B-cinema.html`: высокий трек задаёт длину
прокрутки, сцена внутри залипает, прогресс скролла крутит кроссфейд глав и заполняет рельс.
Так четыре блока живут в одном экране вместо того, чтобы тянуться вниз с пустотой между ними.

Две правки против оригинала B. Первая: главы перекрываются — следующая начинает проявляться
до своего сегмента, иначе на стыке возникает провал в пустоту (минимальная суммарная видимость
поднята с 0.00 до 0.82). Вторая: цикл `requestAnimationFrame` крутится только пока сцена в кадре,
а не постоянно.

Залипание включается скриптом (класс `.pinned`) и только на ширине от 981 px без
`prefers-reduced-motion`. Без JS, на мобильном и при отключённой анимации — обычный список
из четырёх блоков.

Все анимации медленные намеренно: посетитель приходит в состоянии, где резкое движение читается
как угроза (`proto/ANTI-SLOP.md`, раздел про психологический продукт).

## Файлы

```
index.html      вся страница
privacy.html    обработка данных (для формы почты)
styles.css      стили, @font-face, вся арт-дирекция
content.md      источник правды по тексту — правьте здесь
assets/fonts/   Onest, Cormorant Garamond, JetBrains Mono (кириллица + латиница, ~147 КБ)
proto/          пять исходных вариантов лендинга + METHODOLOGY.md + ANTI-SLOP.md
refs/           cookbook.md — Frontend Aesthetics от Anthropic
```

`proto/ANTI-SLOP.md` — правила против нейрослопа. **Перед любой правкой фронтенда прочитать и
следовать буквально**: раздел «Запрещено» жёсткий (никаких `·` между словами, клавиатурных стрелок,
заливки с обводкой и тенью одновременно, капслок-лейблов с тире).

## Запуск локально

Открывать `index.html` двойным кликом нельзя — нужен сервер:

```bash
python -m http.server 4173
```

http://localhost:4173

## Деплой

1. Запушить в `main`.
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)`.
   Не через свой GitHub Actions workflow — иначе `CNAME` будет игнорироваться при каждом деплое.
3. **Репозиторий должен быть публичным** — Pages на бесплатном плане не работает с приватными.

## Что ещё не сделано

- **Форма** ничего не отправляет: JS перехватывает submit и показывает «спасибо», чтобы можно было
  смотреть страницу локально. Перед публикацией — Formspree/Tally или свой Worker,
  см. LANDING_PLAN.md §5.1.
- **`privacy.html`** — три незаполненных места: оператор данных, срок хранения, контакт.
  Без них форма с чекбоксом согласия юридически бессмысленна.
- **`robots.txt` / `sitemap.xml`** — заглушки вместо реального домена.
- **OG-картинка** (`assets/og-image.png`, 1200×630) не нарисована: превью ссылки в мессенджерах
  будет без изображения.
- **Открытые решения** — домен, куда ведёт форма, EN-версия: LANDING_PLAN.md §12.
