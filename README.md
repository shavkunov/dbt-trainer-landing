# DBT-тренажёр — лендинг

Статический лендинг продукта [`dbt_trainer`](../dbt_trainer). Один HTML-файл, один CSS-файл, без
сборки и зависимостей. Живёт отдельным репозиторием от продукта — см.
`dbt_trainer/planning/LANDING_PLAN.md` за полным обоснованием решений.

## Файлы

```
index.html      вся страница
privacy.html    политика обработки данных (для формы почты)
styles.css      стили; токены совпадают с frontend/src/app/globals.css продукта
content.md      источник правды по тексту — правьте здесь, потом переносите в index.html
assets/         favicon, будущие изображения и самохостинг шрифтов
robots.txt, sitemap.xml, .nojekyll   технические файлы для GitHub Pages
```

## Запуск локально

Открывать `index.html` двойным кликом **нельзя** — относительные пути и `fetch` ведут себя иначе
на `file://`. Поднимайте локальный сервер:

```bash
python -m http.server 4173
```

Открыть http://localhost:4173

## Деплой (когда будете готовы публиковать)

1. Создать репозиторий на GitHub, запушить содержимое этой папки в ветку `main`.
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)`.
   Не через custom GitHub Actions — иначе файл `CNAME` (после подключения домена) будет
   игнорироваться при каждом деплое.
3. Проверить боевой URL по чеклисту в `dbt_trainer/planning/LANDING_PLAN.md`, §10.

## Что ещё не сделано (осознанно, до вашего решения)

- **Форма** сейчас ничего никуда не отправляет — JS в `index.html` перехватывает submit и просто
  показывает «спасибо», чтобы можно было смотреть страницу локально. Перед реальной публикацией:
  завести форму в Formspree/Tally (или своём Cloudflare Worker) и заменить обработчик в `index.html`
  на настоящий `action`/`fetch`. См. LANDING_PLAN.md §5.1.
- **`privacy.html`** содержит два `TODO`: оператор данных и контакт для обращений. Заполнить перед
  публикацией — без этого форма с чекбоксом согласия юридически бессмысленна.
- **`robots.txt` / `sitemap.xml`** содержат заглушки вместо реального домена — обновить при деплое.
- **Шрифты**: сейчас страница использует системный serif/sans (без внешних запросов). Если решите
  вернуть фирменные Fraunces/Source Sans 3 (как в приложении) — самохостить файлы в
  `assets/fonts/` и подключить через `@font-face`, не через Google Fonts CDN (см. LANDING_PLAN.md §6).
- **OG-картинка** (`assets/og-image.png`, 1200×630) не создана — сейчас превью ссылки в
  мессенджерах будет без изображения. Добавить перед публикацией.
- **Открытые продуктовые решения** (владелец репозитория, домен, куда ведёт форма, EN-версия) —
  см. LANDING_PLAN.md §12.
